# Дневник атмосферы — Genesis Hackathon · ArtTech

> Make the Invisible Visible: текст, фото и песня дня превращаются в анимированную страницу дневника,
> которая передаёт не то, как день выглядел, а то, как он ощущался.

**Прототип онлайн:** https://abil-truescope.github.io/genesis/

## Быстрый старт

**Вариант 1. Один файл, без установки.** Откройте `dist/index.html` двойным кликом в Chrome или Edge.

**Вариант 2. Из исходников.**
```bash
npm run start        # статический сервер на http://localhost:5173
# или: python3 -m http.server 5173
```
Модули ES не открываются через `file://`, поэтому исходники нужно запускать через любой локальный сервер.

**Пересобрать один файл:** `npm install && npm run build` → `dist/index.html`.

**Проверка:** нажмите «Добавить 5 демо-дней» в архиве. Приложение синтезирует фото и музыку и прогонит их через полный конвейер.

## Что умеет прототип

| Требование кейса | Где реализовано |
|---|---|
| Ввод: текст, фото (1+), песня (ссылка или файл) | `js/main.js` → форма «Новый день» |
| Воспоминание строится из ввода, а не из шаблона | `js/system/mapping.js` + `js/render/*` |
| Музыка влияет на оформление и звучит при просмотре | `js/analyze/audio.js`: BPM, энергия, лад; кадры меняются в долю; плеер/embed в папке дня |
| Папка дня с придуманным названием | `js/analyze/text.js` → `makeTitle`; zip-экспорт папки в `js/export.js` |
| Архив, к любому дню можно вернуться | IndexedDB (`js/db.js`), лента в «Архиве», листание ← → |
| Единая визуальная система, 3+ дня с разным настроением | 4 приёма + плёнка, постоянная сетка, см. `docs/TECHNIQUES.md` |
| Озвучка голосом под атмосферу (плюс) | `js/voice.js`: скорость и высота по энергии и настроению |
| Объяснимая логика | кнопка «Почему так?» показывает каждое правило, которое сработало |
| Видео | «Видео» → WebM со звуком (для своего аудиофайла) |
| Удобство ввода | мастер из 3 шагов; пока пишете, дневник показывает настроение и будущее название папки |
| Удобство архива | главная с полосой последних 14 дней и блоком «В этот день», архив: лента, календарь, поиск, фильтр по приёму |
| Аккаунты | вход через Google (`docs/GOOGLE_SIGNIN.md`), у каждого аккаунта свой дневник на устройстве; гостевой режим |
| Приватность | всё хранится в браузере пользователя, согласие при первом входе, политика (`#privacy`), экспорт и удаление всех данных |

## Как это работает

```
текст ─► словарь настроений (+ Gemini, если есть ключ) ─┐
фото  ─► k-means палитра, яркость, теплота ─────────────┼─► combineMood ─► chooseStyle ─► buildParams ─► рендер 4:5
песня ─► BPM / энергия / лад / фаза доли (аудио)        │        (6 осей)    (4 приёма)    (палитра, ритм,       │
         или жанр + год (по описанию) ──────────────────┘                                  воздух, зерно, голос)  ▼
                                                                                  папка дня → архив → zip / видео
```

Без внешних API всё работает офлайн. Gemini необязателен (⚙ → ключ): он уточняет оси настроения и
придумывает название, но результат всё равно проходит через правила системы.

## Структура

```
index.html, css/style.css
js/main.js            интерфейс: главная / мастер записи / архив / папка дня / настройки / политика
js/ui.js              иконки, уведомления, модальные окна
js/auth.js            вход через Google (Google Identity Services), отдельный дневник на аккаунт
js/privacy.js         политика конфиденциальности и условия
js/config.js          Google Client ID и контакты
js/pipeline.js        конвейер ввод → анализ → правила → воспоминание → сохранение
js/analyze/text.js    словарь настроений RU, сезон, время суток, место, название папки, подпись
js/analyze/llm.js     необязательный Gemini (JSON-схема), слияние с правилами 70/30
js/analyze/image.js   палитра (k-means++), яркость, насыщенность, теплота
js/analyze/audio.js   FFT, BPM (автокорреляция spectral flux), лад (профили Крумхансла), embed-ссылки
js/system/mapping.js  ВИЗУАЛЬНАЯ СИСТЕМА: правила и объяснения
js/render/styles.js   Моне, Ма, Матисс, Кандинский, плёнка
js/render/renderer.js постоянная сетка 1080×1350, анимация, синхронизация с долей
js/voice.js           озвучка Web Speech API
js/export.js          WebM-запись, zip папки дня
js/demo.js            демо-сцены и синтез демо-треков
tools/smoke.py        e2e-тест в headless Chrome (playwright)
```

## Публикация на GitHub Pages

Settings → Pages → Build and deployment → Source: **Deploy from a branch** → Branch: `main`, папка `/ (root)` → Save.
Через 1–2 минуты сайт откроется по адресу `https://abil-truescope.github.io/genesis/`.

## Права и этика

- Чужие песни не хранятся: аудиофайл только анализируется (темп, лад, энергия) и сохраняется, лишь если пользователь отметил, что это его запись или трек со свободной лицензией. Для прослушивания используется официальный плеер сервиса по ссылке.
- Сервера с данными нет: записи, фото и аккаунт хранятся в IndexedDB/localStorage браузера. Политика конфиденциальности — в приложении (`#privacy`).
- Голоса синтезированные (системные голоса ОС).
- Стили художников используются как приёмы (мазок, геометрия, вырезка), конкретные работы не копируются.
- Оценки настроения — художественный инструмент, а не психологическая диагностика.
